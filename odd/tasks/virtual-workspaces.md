# Virtual workspaces for macOS

## Objective and constraints
Build a responsive, low-idle-cost macOS virtual workspace manager with per-display workspaces, friendly configuration, and measured switching. SIP stays enabled; use public APIs and event-driven idle behavior, not permanent capture or private compositor hooks. The user chose parking inactive windows at a free offscreen display corner rather than minimizing. This is a prototype, not guaranteed complete hiding or an AeroSpace performance improvement. AeroSpace documents one-pixel remnants and corner conflicts: https://github.com/nikitabobko/AeroSpace/blob/main/docs/guide.adoc#emulation-of-virtual-workspaces.

Acceptance: independent per-display switches; explicit safe window move/restore with failure recovery; useful menu permission/state and simple workspace names; real one/two-display latency and idle CPU/memory evidence. Out of scope: compositor-equivalent effects, Metal snapshots, broad theme engine, installer, CLI. Unsupported AX/fullscreen apps and display disconnect must degrade visibly, never silently strand windows.
