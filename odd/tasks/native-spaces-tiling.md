# Native Spaces + conservative Gio tiling

## Goal and constraints
Replace Gio's virtual offscreen parking/workspace switching with macOS Spaces for desktop changes. Preserve Gio's opt-in per-display balanced tiling, verified AX frame writes, rollback, safe Quit restoration, and low-idle event-driven behavior. The user chose native Spaces, and explicitly accepted that windows without sufficiently confident active-Space evidence are skipped. SIP stays enabled; no private CGS/WindowServer APIs, screen capture, TCC reset, or claim of measured performance improvement.

## Evidence and design boundary
A real signed Gio.app run with Accessibility Granted failed: `positionMismatch(requested: (-1799, 1168), actual: (-1799, 1128))`, rollbackFailures empty. macOS altered the requested parking Y by 40 points, so virtual offscreen parking is not reliable on this host. `linkd.autoShortcut` XPC messages are not the AX diagnosis. Apple documents `NSWorkspace.activeSpaceDidChangeNotification` (notification without Space ID, through workspace notificationCenter) and `CGWindowListOption.optionOnScreenOnly`, but provides no documented public arbitrary-Space switching/assignment or direct AXUIElement-to-CGWindowID mapping. On-screen AX-to-CG correlation using PID, exact title and geometry is heuristic: require unique, recent matches across all enumerated AX windows and CG windows; skip missing/ambiguous evidence. Never treat a Space-change notification or PID-only/title-only similarity as authority to move a window. No assumption that all windows can be tiled.
